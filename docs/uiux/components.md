# 🧩 Components

## Button

### Primary

Digunakan untuk aksi utama.

Contoh:

- Simpan
- Tambah

---

### Secondary

Digunakan untuk aksi tambahan.

---

### Danger

Digunakan untuk:

- Hapus

---

## Card

Digunakan untuk:

- Statistik
- Form
- Tabel

---

## Table

Semua tabel memiliki:

- Search
- Pagination
- Sorting
- Empty State

---

## Modal

Digunakan untuk:

- Konfirmasi hapus
- Detail data
