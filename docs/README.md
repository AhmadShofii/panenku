# 🌾 PanenKu

PanenKu adalah aplikasi manajemen hasil panen berbasis Web dan Mobile yang membantu petani dalam mengelola data kebun, hasil panen, biaya operasional, dan laporan.

---

- CodeIgniter 4
- PHP 8.5
- MySQL

### Frontend Web

- Bootstrap 5
- JavaScript
- AdminLTE

### Mobile

- Flutter

## Kenapa saya ingin mulai dari dokumentasi?

Karena saat proyek sudah besar (puluhan controller, model, tabel, dan API), dokumentasi akan sangat membantu. Selain itu, dokumentasi yang baik juga menjadi nilai tambah ketika proyek dijadikan portofolio atau dinilai oleh dosen.

Cara kerja kita ke depan

Agar konsisten, setiap tahap akan mengikuti alur ini:

Planning – Menentukan kebutuhan fitur.
Documentation – Menulis perubahan atau keputusan penting.
Implementation – Menulis kode.
Testing – Menguji fitur.
Review & Refactor – Merapikan kode sebelum lanjut ke fitur berikutnya.

Dengan alur ini, proyek akan tetap terstruktur dan lebih mudah dikembangkan.

Sprint setelah Foundation

Setelah dokumentasi dasar selesai, kita lanjut ke:

Desain database (ERD)
Membuat database MySQL
Konfigurasi CodeIgniter 4
Autentikasi (Login, Register, Logout)

Menurut saya, ini urutan yang paling aman dan profesional untuk PanenKu. Kita membangun fondasi dulu, baru masuk ke implementasi fitur.
